要不要用 AI？

不用

主要功能照常

  • 盯盤、提醒、通知、回測
  • 用表單設提醒
  • 不用註冊，不用付錢

用 AI

多兩件事

  • 一句話產生策略
  • 出問題時可以問它
  • 費用你自己的，有免費模型
先跳過也行。之後在系統裡貼一把金鑰就恢復。

要用的話：拿一把金鑰，先存著

五分鐘。金鑰在第 3 步填進去。

OpenRouter — 一把金鑰用很多家，有免費模型
  1. 開 openrouter.ai，右上 Sign in，用 Google 登入。
  2. 開 openrouter.ai/keys，按 Create Key。
  3. 名字隨便打，Credit limit 留空，按 Create。
  4. 複製 sk-or-v1-…，關掉就看不到完整的了。

系統裡填：供應者「OpenAI 相容」，網址 https://openrouter.ai/api/v1。

不用綁卡。只挑名字結尾有 :free 的模型就不會產生費用。

NVIDIA — 免費額度大方，模型很多
  1. 開 build.nvidia.com，用 Google 或 email 註冊。
  2. 隨便點一個模型（例如 Llama 3.3 70B），右上角按 Get API Key。
  3. 按 Generate Key，複製 nvapi-…。

系統裡填：供應者「OpenAI 相容」，網址 https://integrate.api.nvidia.com/v1。 模型從系統的下拉選單挑——它會去問供應商現在有哪些。

註冊即送額度，不用綁卡。額度用完就停，不會自動扣款。 畫面偶爾會改版，找不到就找「API Key」這個字。

Groq — 免費，回應非常快
  1. 開 console.groq.com/keys，用 Google 登入。
  2. 按 Create API Key，複製 gsk_…。

系統裡填：供應者「OpenAI 相容」，網址 https://api.groq.com/openai/v1。 模型從下拉選單挑，不要用手打。

畫面偶爾會改版，找不到就找「API Keys」這個字。

OpenAI 或 Anthropic — 付費，品質最穩

OpenAI：platform.openai.com/api-keys， 網址填 https://api.openai.com/v1。

Anthropic：console.anthropic.com， 供應者選「Anthropic」，網址不用改。

這兩家要先儲值，用多少扣多少。

那這把金鑰要填在哪裡？

要讓系統用它，兩個地方選一個：

  1. 第 3 步部署的時候——表單上有一格 AI_API_KEY，貼進去。
  2. 裝完之後——系統左邊選單 AI 輔助，貼上、儲存、按測試連線。

這兩個地方都會把金鑰加密存進你自己那份部署的資料庫。

下面那一格是另一回事：它只讓這份引導的第 2、3 步能問 AI， 金鑰留在你這個瀏覽器分頁裡、關掉就沒了。 在那裡貼過，不等於系統設定好了——裝完之後還是要照上面兩條做一次。
