要不要用 AI？

不用

主要功能照常

  • 盯盤、提醒、通知、回測
  • 用表單設提醒
  • 不用註冊，不用付錢

用 AI

多兩件事

  • 一句話產生策略
  • 出問題時可以問它
  • 費用你自己的，有免費模型
先跳過也行。之後在系統裡貼一把金鑰就恢復。

要用的話：拿一把金鑰，先存著

五分鐘。金鑰在第 3 步填進去。

手把手：在 OpenRouter 拿金鑰
  1. 開 openrouter.ai，右上角 Sign in，用 Google 帳號登入。
  2. 登入後開 openrouter.ai/keys。
  3. 按 Create Key，名字隨便打（例如 stock-alerts），Credit limit 留空。
  4. 按 Create，畫面會給你一串 sk-or-v1-…。
  5. 複製它，貼在記事本先存著。關掉視窗之後就看不到完整的了。

不用綁信用卡。只用免費模型（名字結尾有 :free）就不會產生費用， 系統預設就是選免費的。

那這把金鑰要填在哪裡？

兩個地方都可以，選一個：

  1. 第 3 步部署的時候——部署表單上有一格叫 AI_API_KEY，貼進去就好。
  2. 裝完之後——在系統左邊選單的 AI 輔助，貼上、按儲存、按測試連線。

這一頁存不了你的金鑰，它只是 GitHub 上的一個檔案，沒有後端也沒有資料庫。 金鑰只會進到你自己那一份部署，加密後存在你自己的資料庫裡。

想用 OpenAI 或 Anthropic 的金鑰

也可以，裝完之後在「AI 輔助」那一頁改兩個欄位：

  1. OpenAI：供應者選「OpenAI 相容」，網址填 https://api.openai.com/v1。
  2. Anthropic：供應者選「Anthropic」，網址不用改。
