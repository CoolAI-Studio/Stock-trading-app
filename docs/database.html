資料放哪裡。

差別只有一件事：電腦關機的時候會怎樣。

不確定就選雲端。它的價值在你沒看盤的時候。之後改得掉。
那這一頁不用做。不用申請、不用註冊。 跳到第 3 步：安裝 →

你只需要拿到一串字

唯一要去別人家拿的東西。 其他空白，設定頁都有按鈕當場生出來。

叫做連線字串，長得像 postgresql://使用者:密碼@主機/資料庫名。 註冊完資料庫服務，它就會給你這一串——你只要複製，不用看懂。

最省事：用部署平台自己的資料庫（但會到期）

Render、Railway 這些平台自己就有 Postgres，開下去會自動接上—— 這一格完全不用填，也不用再註冊一家。

代價要先知道：免費的那一種有期限，而到期是把資料庫連同 裡面的東西一起刪掉，不是停用。你的帳號、策略、通知設定 會在某一天全部消失，而且事前不會有人提醒你。期限多長各家不同也調整過， 以你在那個平台上看到的為準。

所以它適合「先試試看這東西合不合用」。決定長期用的話，換成下面任何一個 不會到期的，再把資料倒過去——不過那件事要你自己記得做。

Neon — 免費，不用信用卡，設定最快
  1. 開 neon.tech，按 Sign up，用 Google 或 GitHub 登入。
  2. 它會自動幫你建一個 project，不用改任何設定，直接按下一步到底。
  3. 進到 Dashboard，找 Connection string 那一塊。
  4. 按旁邊的複製按鈕，拿到 postgresql://… 開頭的一串。
  5. 貼在記事本先存著，第 3 步要用。

如果它問你要 Pooled 還是 Direct，兩個都可以，選預設的就好。 畫面偶爾會改版，找不到就在頁面上找「Connection string」這個字。

先知道這件事：它每個月會停一次。Neon 免費方案給的是每月的 運算時數額度（100 CU-hours，官方換算是 400 小時），閒置五分鐘 才休眠而且關不掉——但這個系統為了盯盤，收盤後也每五分鐘碰一次資料庫，所以它幾乎 不會休眠。一個月 730 小時、額度 400 小時，大概第十七天就用完， 然後停到下一個帳單週期。停著的那半個月，一則提醒都不會送出。 長期一直跑的話，下面那個沒有這個限制。

Supabase — 同樣免費，長期一直跑比較適合（推薦）
  1. 開 supabase.com，按 Start your project。
  2. 建一個 New project。它會要你設一個資料庫密碼——設一個並記下來。
  3. 等它建好（約兩分鐘）。
  4. 左下角 Project Settings → Database → 找 Connection string，選 URI。
  5. 複製那一串。

最容易卡住的一步：它給你的那串裡有 [YOUR-PASSWORD]，你要自己把它換成第 2 步設的那個密碼， 連中括號一起換掉。沒換的話系統會說連不上。 畫面偶爾會改版，找不到就找「Connection string」或「URI」。

為什麼長期一直跑推薦這一個：它沒有每月的運算時數額度，只有 「一整個星期沒人用就暫停」——而這個系統每五分鐘就碰一次資料庫，所以那條永遠不 會踩到。比較麻煩的只有上面那個密碼要自己換。

付費方案、或你自己架的 Postgres

都可以，這個系統不在乎是誰家的。自己架的話，把那串連線字串準備好就行。

免費方案有一件事值得先知道。「沒人用就休眠、醒來等幾秒」不是 全部——有些家（Neon 是其中一個）給的是每月的運算時數額度，而 這個系統為了盯盤，收盤後也每五分鐘碰一次資料庫，所以那顆運算單元幾乎不會休眠。 額度用完會被停到下一個帳單週期，而那大概是每個月第十七天前後。停著的那半個月， 一則提醒都不會送出。

你會知道它發生了（保活監控會寄信，信裡就寫著這個原因），但要它整個月都在， 就得升級方案，或挑一家不是用運算時數計費的。

Render、Railway、Fly.io、Koyeb 自己也都能開 Postgres， 在他們的後台按 New → PostgreSQL，一樣是複製那串連線字串。

其餘一樣

它要的是兩樣東西，不是三個品牌。每一格都能換。

跑 Docker 的地方 — 免費例子：Render

它負責盯盤、跑策略、送通知，是這個系統的本體。

也可以：Railway、Fly.io、Koyeb、Heroku，或你自己的機器。 它們要的是同一件事——用 backend/Dockerfile 建一個容器。

一個 Postgres — 免費例子：Neon、Supabase

存你的帳號、策略、提醒紀錄。上面已經有手把手。

也可以：任何 Postgres，含付費方案和自己架的。

放前端的地方 — 不需要

畫面跟 API 出自同一份部署，所以沒有第三樣東西要準備， 也沒有第二個網址要對起來。

想把畫面另外放在 Vercel、Cloudflare Pages、Netlify 也照樣可以—— 那是一個選擇，不是一個要求。安裝那一頁有做法。
