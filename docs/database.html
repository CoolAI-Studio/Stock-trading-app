差別只有一件事：電腦關機的時候會怎樣。

自己的電腦

硬碟上一個檔案

  • 不用註冊，不用信用卡
  • 關機就停止盯盤
  • 要自己備份

雲端

你關電腦它照樣在跑

  • 手機在哪裡都收得到
  • 有免費方案，多數不用卡
  • 免費方案會休眠，醒來等幾秒
不確定就選雲端。它的價值在你沒看盤的時候。之後改得掉。

雲端用哪一家

它要的是三樣東西，不是三個品牌。

要的東西免費的例子也可以
跑 Docker Render Railway、Fly.io、Koyeb、自己的機器
一個 Postgres Neon、Supabase 任何 Postgres，含自架
放前端 Vercel Cloudflare Pages、Netlify
只有資料庫要去別人家拿：一串 postgresql:// 開頭的連線字串。其餘系統自己產生。
