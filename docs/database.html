差別只有一件事：電腦關機的時候會怎樣。

自己的電腦

硬碟上一個檔案

  • 不用註冊，不用信用卡
  • 關機就停止盯盤
  • 要自己備份

雲端

你關電腦它照樣在跑

  • 手機在哪裡都收得到
  • 有免費方案，多數不用卡
  • 要開一個 Postgres（下面有手把手）
不確定就選雲端。它的價值在你沒看盤的時候。之後改得掉。

你只需要拿到一串字

叫做連線字串，長得像 postgresql://使用者:密碼@主機/資料庫名。 註冊完資料庫服務，它就會給你這一串——你只要複製，不用看懂。

Neon — 免費，不用信用卡（推薦第一次用）
  1. 開 neon.tech，按 Sign up，用 Google 或 GitHub 登入。
  2. 它會自動幫你建一個 project，不用改任何設定，直接按下一步到底。
  3. 進到 Dashboard，找 Connection string 那一塊。
  4. 按旁邊的複製按鈕，拿到 postgresql://… 開頭的一串。
  5. 貼在記事本先存著，第 3 步要用。

如果它問你要 Pooled 還是 Direct，兩個都可以，選預設的就好。 畫面偶爾會改版，找不到就在頁面上找「Connection string」這個字。

Supabase — 免費，同樣是 Postgres
  1. 開 supabase.com，按 Start your project。
  2. 建一個 New project。它會要你設一個資料庫密碼——設一個並記下來。
  3. 等它建好（約兩分鐘）。
  4. 左下角 Project Settings → Database → 找 Connection string，選 URI。
  5. 複製那一串。

最容易卡住的一步：它給你的那串裡有 [YOUR-PASSWORD]，你要自己把它換成第 2 步設的那個密碼， 連中括號一起換掉。沒換的話系統會說連不上。 畫面偶爾會改版，找不到就找「Connection string」或「URI」。

付費方案、或你自己架的 Postgres

都可以，這個系統不在乎是誰家的。免費方案在沒人用的時候會休眠，醒來要等幾秒； 在意這件事就用付費方案。自己架的話，把那串連線字串準備好就行。

Render、Railway、Fly.io、Koyeb 自己也都能開 Postgres， 在他們的後台按 New → PostgreSQL，一樣是複製那串連線字串。

其餘兩樣

它要的是三樣東西，不是三個品牌。每一格都能換。

跑 Docker 的地方 — 免費例子：Render

它負責盯盤、跑策略、送通知，是這個系統的本體。

也可以：Railway、Fly.io、Koyeb、Heroku，或你自己的機器。 它們要的是同一件事——用 backend/Dockerfile 建一個容器。

一個 Postgres — 免費例子：Neon、Supabase

存你的帳號、策略、提醒紀錄。上面已經有手把手。

也可以：任何 Postgres，含付費方案和自己架的。

放前端的地方 — 免費例子：Vercel

你在瀏覽器上看到的畫面，就是一堆靜態檔。

也可以：Cloudflare Pages、Netlify，或任何能放靜態檔的地方。
