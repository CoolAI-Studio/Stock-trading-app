十五分鐘。

最花時間的是第一步。其餘系統會帶你走。

  1. 開一個 Postgres

    複製它給你的連線字串。

  2. 部署後端

    用 backend/Dockerfile。只填 DATABASE_URL，其餘留白。

  3. 部署前端

    只填後端網址。

  4. 打開你的網址

    設定頁會列出還缺什麼，能產生的都有按鈕。

  5. 建立帳號

    第一個也是唯一一個。建好後註冊自動關閉。

  6. 接上三件事

    資料庫、AI、通知。每一格都要按到通為止。

在自己電腦上跑：docker compose up，然後從第 4 步開始。
