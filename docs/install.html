照著做就好。

約十五分鐘。手邊要有第 2 步的連線字串， 還有第 1 步的金鑰（沒有也行）。

  1. 建立後端

    按這顆按鈕，用 GitHub 帳號登入 Render，它會照著設定檔幫你建好。

    在 Render 建立後端

    畫面上會問我什麼？
    1. DATABASE_URL — 貼第 2 步那串 postgresql://…
    2. AI_API_KEY — 貼第 1 步那串 sk-or-v1-…。沒有就留空
    3. AI_MODEL — 留空
    4. 其他每一格都留空，包括看起來很重要的那些

    留空不是偷懶。加密金鑰那幾格等一下在系統的網頁上按按鈕產生， 不用在你自己的電腦上裝任何東西。

    不想用 Render — Railway 怎麼做
    1. 開 railway.app，用 GitHub 登入。
    2. New Project → Deploy from GitHub repo， 選這個專案（先在 GitHub 上按 Fork 複製一份到你的帳號）。
    3. Settings → Root Directory 填 backend。
    4. Variables 加上 DATABASE_URL （和選填的 AI_API_KEY）。
    5. Settings → Generate Domain，拿到你的後端網址。

    畫面偶爾會改版，找不到就找「Root Directory」和 「Variables」這兩個字。

    不想用 Render — Fly.io 怎麼做
    1. 裝 flyctl，然後 fly auth signup。
    2. 下載這個專案，在 backend 資料夾裡執行 fly launch。
    3. 它問要不要建資料庫時選 Yes，Fly 會自己設好 DATABASE_URL。
    4. fly deploy。

    這條路要打指令。不習慣終端機的話用上面兩家。

    不想用 Render — 我自己有一台機器
    1. 那台機器要裝 Docker。
    2. 下載這個專案，在 backend 資料夾執行 docker build -t stock-alerts .
    3. docker run -p 8000:8000 -e DATABASE_URL=… stock-alerts

    要從外面連得到的話，那台機器需要一個對外網址和 HTTPS。

  2. 抄下後端網址

    建好之後 Render 會給你一個 https://xxx.onrender.com，在頁面最上面。複製它。

    第一次啟動要等三到五分鐘。中間看到錯誤畫面是正常的。

  3. 建立前端

    按這顆，同樣用 GitHub 登入。

    在 Vercel 建立前端

    畫面上會問我什麼？
    1. 只有一格：VITE_API_BASE_URL
    2. 貼上一步抄下來的後端網址，結尾不要有斜線
    3. 按 Deploy，等一分鐘

  4. 打開你的網址

    Vercel 給你的 https://xxx.vercel.app。 畫面會自己帶你到設定頁，上面列著還缺什麼。

  5. 按產生、貼回去

    設定頁上每一項能自己產生的都有一顆「產生」按鈕。 按一下、複製、貼回 Render。

    貼回 Render 的哪裡？
    1. 回 Render 後台，點你的服務。
    2. 左邊選單 Environment。
    3. 找到同名的那一格（例如 SECRET_ENCRYPTION_KEY），把值貼進去。
    4. 按 Save。Render 會自動重新部署，約兩分鐘。
    5. 回到設定頁按重新整理，那一項就消失了。

    還有一格叫 CORS_ORIGINS：設定頁會直接把該填的網址印出來給你複製， 不用自己找。

  6. 建立你的帳號

    設定頁說完成之後重新整理，畫面會請你建立帳號—— 第一個也是唯一一個。建好之後註冊自動關閉。

  7. 接上通知

    進去之後系統會帶你走引導：資料庫、AI、通知。 每一格都要按到「通了」為止，填了不算。

我要跑在自己的電腦上，不用雲端
  1. 裝 Docker Desktop。
  2. 下載這個專案（GitHub 頁面上綠色的 Code → Download ZIP），解壓縮。
  3. 在那個資料夾裡開終端機，輸入 docker compose up。
  4. 瀏覽器開 http://localhost:5173，從上面第 4 步繼續。

資料會存在你電腦上的一個檔案裡。電腦關機或睡著，盯盤就停了。

卡住了

問 AI（用你第 1 步存的金鑰）
畫面說「讀不到歷史資料」或一片空白

多半是後端還在醒（免費方案閒置後會休眠，冷啟動約一分鐘）。等一下重新整理。 一直這樣的話，看看 CORS_ORIGINS 是不是填了你的前端網址。

設定頁說資料庫連不上

連線字串多半貼漏了或密碼沒換。用 Supabase 的話，檢查那串裡的 [YOUR-PASSWORD] 有沒有換成你設的密碼。回資料庫服務重新複製一次最快。

還是不行

每一個設定值的完整說明在 部署說明； 真的卡住可以到 Issues 問。
